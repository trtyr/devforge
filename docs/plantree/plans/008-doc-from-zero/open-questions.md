## 已关闭项详情：Q013

**做法已定（D010 / RepoDoc 语义影响传播）**：
1. 变更检测：commit diff + AST 定位到实体级
2. **语义影响传播**：在知识图（codegraph）上**双向遍历**，找受影响模块（RepoDoc 实测更新召回 97% vs 全量重生成 88%）
3. 选择性重生成：只动受影响文档，保留未变内容
4. 一致性校验：链接/图引用/模块文档是否反映子部件

仍未定的：这套增量是**内置在本 SOP**（`--update <commit>`）还是单独做一道链。
