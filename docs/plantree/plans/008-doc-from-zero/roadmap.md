## Milestones

- **M0**（Phase 0）：契约 + doc-lint 落地，coding 链路用上（P008 的前置，也是 P005/P007 的增量）

- M1（A 段）：清单能机械产出，且覆盖一个真实中型库
- M2（B+C 段）：能产出通过五项审计（覆盖/完整性/真实性/置信度诚实性/可跑）的文档体系
- M3（E 段）：作为 SOP 被 API 触发、端到端跑通
