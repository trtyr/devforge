# T021 · M3 端到端（doc-from-zero 单仓跑通）

**状态**：运行中（2026-10-19 夜）／结果以运行日志与本文件末节为准。

## 为什么用 fixture 而不是直接啃陌生大仓

M3 的验收问题是「SOP 能不能把一套文档从零产出来、并过五项审计」，不是「模型够不够聪明」。
所以第一个见证用**受控 fixture**：无文档、无 git、规模小到能看懂全貌——这样任何失败都先归因到流程，而不是归因到仓库复杂度。

fixture（`tests/e2e/test_22_doc_from_zero.py` 内联生成）：

```
book-app/
├── main.py            # 入口，import booklib.core
└── booklib/
    ├── __init__.py
    └── core.py        # add_book / list_books（公开）+ _reset_for_tests（私有）
```

四类诱因是刻意埋的：
- `main.py` 是入口 → 入口可达闭包有真实路径可走；
- `booklib/` 是子包 → 单元划分与导入解析要能解析 `booklib.core`；
- `_reset_for_tests` 私有 → 符号覆盖只收公开符号，不能把私有当必填；
- **完全没有 docs、没有 .git** → 文档必须凭空长出来，不许借 git 历史。

## 验收断言（脚本里可判的部分）

| 面 | 断言 |
| --- | --- |
| 门 0 | `_meta/inventory.json` 落盘；每个 module 条目都带 `unit_id`；`_meta/glossary.md` 自动导出；`_meta/gate0-closures.md` 有闭包证据 |
| 单元滚动 | `_meta/state.json` 存在且 `done` 非空；`docs/contexts/` 下出现正文 `.md` |
| 执行取证 | `sessions/doc` 与 `sessions/doc-reviews` 都有内容（写方与审方都真跑过，不是脚本自嗨） |
| 终审 | `_meta/runs/<run-id>/report.md` 存在，含「单元完成 / 审查轮次」 |
| 复算 | `devforge doc-audit <docs> --repo <repo>` 退出码 0（覆盖 + lint 的机械部分现场重算，不信 run 的自述） |

最后一条是这套 SOP 的立身之本：**证据必须能被第二个人重算**。所以脚本不读 run 的结论，自己调 CLI 重跑一遍审计。

## 结果

### 第 1 轮（2026-10-19 21:53 起）——失败：审查官死亡 → run 挂死

功的部分（已经证明流程能跑）：

- 门 0 三道产物齐（`inventory.json` / `glossary.md` / `gate0-closures.md`）；
- doc-agent 7 分钟写完 unit-booklib-01：`_meta/facts`、`_meta/interpretation`、`gaps.md`、四篇 entities、两篇 modules、README、runbook；
- 本地用 `devforge doc-audit` 复算：覆盖 7/7、doc-lint 0 违规。

失败的部分：审查官（doc-review）进程在 review-0 读到第 4 篇文档时**静默死亡**，
而它启动的子进程继承了 stdout——引擎的阻塞读永远等不到 EOF，**run 挂死 50+ 分钟，日志一行信号都没有**。

根因链（不是「模型慢」）：

1. `RpcClient::wait_settled` 直接 `BufReader::read_line`，EOF 才退出；
2. pi 死后孙进程（MCP server 等）仍持有 stdout 管道写端，EOF 永不到达；
3. 默认无 run 超时（D002：产品侧不给硬超时），于是无人叫醒它。

修复（commit `a4eed38`）：stdout 交专用线程推送到 channel，读方 `recv_timeout(500ms)` 期间用 `child.try_wait()` 判死，
子进程退出而未见 `agent_settled` → 直接报基础设施故障。回放单测（子进程 exit + 孙进程持管道）证 4 秒内判死。

副产物：`duplicate_mentions` 原来按「符号名出现次数」判跨模块重复，小仓正常文档里 `add_book` 出现在 8 篇 → 全员误杀；
改为按**正文段落**判（`duplicated_content`，归一化 ≥40 字同行、跨 ≥2 篇非 _meta 文档、排除代码块与导航索引），同名出现降为提示级。
