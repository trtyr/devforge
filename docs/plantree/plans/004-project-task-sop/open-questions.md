## Q001 · 项目与本地目录怎么绑定？【已解决 2026-10-16】

**结论：全部手动指定**（用户拍板）。从 0 新项目：用户手动指定在本地哪里创建；已有项目：用户手动指定路径登记进来。无自动约定路径。

## Q002 · SOP 的 MVP 形态？【已解决 2026-10-16】

**结论：SOP 无管理面，全部代码内置**（用户拍板，含一段重要的架构推演）。

原设想三管理面（SOP 拼 Agent、Agent 选模型、模型系统配置），被一个硬问题击碎：**Agent 间产物传递**（上一个 Agent 的产物怎么交给下一个）——这个问题很大，无法做成数据文件、无法做解释器。所以：
- 取消 SOP 管理面，对用户无此概念；内部内置几套 SOP（代码写死）
- 管理面只剩两个：**Agent 管理面**（= PI Agent 配置管理，即 P002）+ **模型管理面**（系统配置模型池，Agent 从池中选，即 P002 模型层）
- 产物传递由编排器代码显式接线（谁产物给谁、怎么给，手写在 SOP 编排代码里）

## Q003 · 并发的实现时机？【已解决 2026-10-16】
